# Kickoff

Resolve the requested outcome, seed, acceptance, budget, and authorization from
the request and existing agreement. Inspect the actual seed and worktree. An
unrelated or exhausted inherited loop is not a new grant. Ask for a genuinely
missing campaign budget; never silently increase it. `--dry-run` prints the
resolved agreement and stops without edits or execution.

Proceed on existing authorization. Use the simplest state that supports this
attempt's coordination and recovery: an existing task record or a short handoff
may suffice. Create `LOOP.md` only when structured campaign control is requested
or needed; load [execution.md](references/execution.md) for that path. A bounded
fix does not become a campaign merely because it takes several steps.

Check actual prerequisites before dependent work. Integrate stable dependencies
before expensive final checks and keep unrelated next-batch work separate.
Missing tools or a human boundary block their dependent work, not independent
authorized progress.

At the outcome, blocker, or budget limit, report completed work, native evidence,
and what remains. Save enough state to resume when necessary; no parallel
status journal is required. A closed campaign does not restart from its old
seed merely because a scheduler invokes it again.
